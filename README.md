# ThreatGraph

A Graph-Based Threat Intelligence and Security Investigation Platform.

## Features

- Dashboard with security statistics
- Database connectivity monitoring
- Threat relationship visualization
- Investigation search for users, devices, IP addresses, and indicators
- Investigation result page with connected entities
- Graph Explorer
- Security Alerts page
- CognoDB integration using the Neo4j Python driver

## Tech Stack

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- CognoDB / Neo4j-compatible graph database
